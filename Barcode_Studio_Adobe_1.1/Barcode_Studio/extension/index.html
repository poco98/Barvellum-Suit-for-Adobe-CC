Text and shape output
Human-readable text uses Amazon Ember Regular at 14 px (10.5 pt). The font is included in the installer. All bars and strokes are expanded to filled vector paths. Text remains text in the SVG.


Which format should I use?
EAN/UPC require the specified number of digits and a valid check digit. Use Code 128 for ordinary letters, digits and references. Use QR Code for a URL, longer text or Unicode. Codes are not registered with GS1 and URLs are not checked online.


Importing products
UTF-8 CSV/TSV, XLSX and JSON are supported. Portuguese and English column headers are recognised. Store codes as text to preserve leading zeros. Scientific notation and imprecise long numeric values are rejected. There is no direct Eticadata/SQL connection or automatic sync with the original file.


Verification limits
Encoder rules and applicable check digits are checked. Independent reading is available only for the formats listed in Verify. A failed reading does not prove invalidity. Confirm final print quality, dimensions, margins and GS1 ownership separately.


Adobe documents
Illustrator: embedded vector SVG. InDesign: embedded SVG on the active page. Photoshop: embedded Smart Object. The SVG uses RGB black; check conversion to 100% K for CMYK print work. Scaling the whole barcode also scales its text.


Compatibility and updates
Windows CEP panel, configured for Illustrator 29–31, Photoshop 26–28 and InDesign 20–22. Close the three apps and run Install.cmd to update. The extension ID and existing database are preserved. This local unsigned build needs CEP PlayerDebugMode, enabled by the installer.
