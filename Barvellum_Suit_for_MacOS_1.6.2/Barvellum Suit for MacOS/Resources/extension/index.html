EAN-13 requires exactly 13 digits. If the check digit is invalid, the panel generates Code 128 with all 13 original digits. Select Use EAN-13 to apply the corrected number to the current preview.

In EAN-13, the gap between the leading digit and the first bar is twice the X dimension. The panel saves your settings locally and reuses them when you switch products.


Illustrator insertion


Select a visible, unlocked layer. The panel centres vector artwork on the active artboard. Standard barcodes are drawn directly in the document. Artwork with more complex SVG features is imported from a temporary document.


In Layers, the editable text group takes the barcode value as its name, for example 5600495642348.


Print checks


Bars are filled vector shapes. Direct insertion into a CMYK Illustrator document uses 100% K for black. Check the final dimensions, the clear space around the bars and readability on the printed label.


QR and link checks


In QR link, paste a URL and select Analyze QR & link. The panel reads the QR image to confirm it contains the exact URL. The link check reports the server response separately, including restricted access, timeouts and browser blocks.


Data and compatibility


In Database, choose Save XLSX template… and pick a folder. Fill in the Reference and Barcode columns, then import the workbook. Both columns are formatted as text to preserve leading zeros.


You can also import CSV, TSV, TXT or JSON and match the two columns. Updates retain the local product database.


Close the Adobe apps before running Install.command. The panel requires CEP. Photoshop on Apple silicon requires Rosetta. See the package README for host versions and setup.
